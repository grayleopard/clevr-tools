# Free Evidence Stack

Use these sources before recommending a paid platform.

## First-party

- Google Search Console UI and Search Analytics API: page/query/device/country performance, indexing, sitemap, links, and URL inspection.
- Product analytics: privacy-safe task funnel events only. Never capture filenames, file contents, calculator inputs, clipboard data, or exception strings.
- Repository tests and integrity reports: advertised behavior, limitations, route status, and artifact truth.

## Free external discovery

- Bing Webmaster Tools: search performance, keyword research, top result URLs, backlinks, Site Explorer, URL submission, and Site Scan.
- Ahrefs Free for the verified domain: own-site keywords, backlinks, referring pages, and technical crawl findings.
- Google Trends: relative topic direction and seasonality, not absolute volume.
- Google Keyword Planner: keyword ideas and volume ranges when the owner has an eligible Ads account.
- Live search result inspection: intent, result type, dominant page format, and current competitors. Record date, country, device, and personalization limitations.
- PageSpeed Insights and CrUX: lab and field experience evidence where available.

## Data discipline

- Cache dated exports in an owner-approved location and do not repeatedly query identical windows.
- Use complete date ranges. Search data commonly lags by two or three days.
- Keep page-only and query-only exports distinct from page + query rows.
- Treat third-party volume and traffic as estimates.
- Do not infer query ownership, cannibalization, or page-level position without page + query evidence.
